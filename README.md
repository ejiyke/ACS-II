# ACS - Accounting & Computer Solutions, Inc. (ACS II)

Modern, warm-editorial web application for **Accounting & Computer Solutions, Inc. (ACS)**, built directly from the high-fidelity Figma design specification (`node-id=2551-185`).

---

## 🏛️ Overview

Accounting & Computer Solutions, Inc. (ACS) delivers high-performance IT strategy, financial systems modernization, and management consulting to federal agencies, state governments, and commercial clients nationwide.

This implementation presents an executive editorial design system featuring rich slate navy surfaces, warm amber accents, elegant typography (`Playfair Display` & `Inter`), and high-resolution architectural photography.

---

## 🚀 Key Sections & Features

- **Header & Navigation**:
  - Sticky glass header with brand mark monogram and navigation.
  - "Schedule Briefing" call-to-action button.
  - Fully responsive mobile drawer navigation.
- **Hero Section**:
  - Eyebrow badge: *"Empowering Public & Private Sectors Through Tech"*.
  - Large editorial typography with warm amber keyword highlights.
  - Dual action buttons (*Our Capabilities* & *Contract Vehicles*).
  - High-resolution luxury corporate atrium imagery.
- **Certifications & Socioeconomic Qualifications Strip**:
  - 5 federal and state procurement credential badges:
    - **SBA 8(a)** - Certified Graduate
    - **HUBZone** - Certified Firm
    - **SDB** - Small Disadvantaged Business
    - **LSDBE** - District of Columbia
    - **MDOT MBE/SDB** - Maryland Certified
- **Capabilities & Specialties**:
  - 4 specialized consulting cards with custom iconography:
    - *Management Consulting*
    - *Financial Systems*
    - *Information Technology*
    - *Sectors & Solutions*
  - Interactive "Read portfolio details →" modal triggers with in-depth practice pillar breakdowns.
- **Strategic Solutions (Case Studies)**:
  - Staggered case study presentations highlighting client challenge and ACS impact:
    - *Federal Agency Systems Overhaul* (with government architecture visual)
    - *Enterprise Cybersecurity Readiness* (with advanced SOC command center visual)
- **Executive Corporate Footer**:
  - 3-column layout covering company bio, direct telephone lines, quick links, and Washington, DC headquarters address.
- **Interactive Modals & Toast System**:
  - Strategic Briefing consultation form with validation and instant toast notification confirmation.
  - Specialty practice deep-dive dialog with focus areas and direct consultation bridge.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic markup, accessible ARIA roles, responsive meta tags.
- **Vanilla CSS3**: Custom design tokens, CSS Grid, Flexbox, responsive breakpoints (Desktop, Tablet, Mobile), micro-animations.
- **JavaScript (ES6+)**: Zero framework dependencies, modal management, smooth scrolling, and toast notification system.
- **Typography**: Google Fonts (`Playfair Display`, `Inter`, `Cinzel`).

---

## 💻 Local Setup

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/ejiyke/ACS-II.git
cd ACS-II
```

Or run a local static server:

```bash
python -m http.server 8080
```
